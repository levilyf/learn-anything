# Teaching loop contract

A lesson should have:

- `outcome`: observable capability the learner should gain.
- `prerequisites`: concepts required before this lesson.
- `explanation`: accurate model at the learner's level.
- `worked_example`: example that demonstrates application.
- `practice`: learner attempt with clear constraints.
- `assessment`: evidence used to judge understanding.
- `feedback`: misconception-specific correction.
- `next_action`: advance, practice, or revisit.

The tutor should adapt based on evidence, not arbitrary completion percentages.
