# Visual revision card

## Purpose

Prompt active recall of one important concept. A diagram, small visual cue, comparison, or mnemonic may support the prompt, but the learner must retrieve the answer.

## Required data

- Stable card ID and concept ID.
- One focused prompt.
- Optional visual cue with a text alternative.
- Expected answer elements or evaluation criteria.
- Common misconception.
- Optional hint, kept separate from the answer.
- Review metadata when available.

## Authoring rules

- Test one concept or relationship per card.
- Prefer questions that require explanation or application over recognition.
- Keep the answer hidden until the learner attempts recall.
- Do not treat card exposure or self-rated confidence as mastery evidence.
- Link successful and failed attempts to the learner's progress record only when persistence is available and authorized.
- Provide a plain-text version for every visual cue.

## Example

**Prompt:** What does DNS provide to a browser when resolving a domain name?

**Visual cue:** Domain name → DNS resolver → IP address.

**Expected answer:** DNS resolution provides an IP address associated with the requested domain name so the browser can attempt to connect to the server.

**Common misconception:** DNS does not deliver the web page itself; it helps resolve a name to network addressing information.
