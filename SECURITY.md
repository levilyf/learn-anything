# Security Policy

## Scope
Learn Anything is an educational framework and agent skill. It is not a security boundary, sandbox, or authorization system.

## Reporting a vulnerability
Do not publish exploitable details in a public issue. Use GitHub's private vulnerability reporting feature if enabled for this repository. Otherwise, contact the maintainers through a private channel listed on the repository profile.

Include the affected version, impact, reproduction steps, and any safe proof of concept. Do not access, modify, or disclose other people's data.

## Safe use
Cybersecurity exercises must be limited to systems the learner owns, has explicit permission to test, or intentionally vulnerable training environments. The skill must not be treated as permission to perform real-world testing.
