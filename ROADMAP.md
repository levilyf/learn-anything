# Roadmap

This roadmap is directional, not a promise of delivery dates.

## v0.1.0 — Teaching-loop prototype
- [x] Initial Agent Skills-compatible entry point.
- [x] Universal teaching workflow specification.
- [x] Cybersecurity beginner module.
- [x] Portable learner and lesson data schemas.
- [x] Structural validation and smoke tests.
- [ ] Validate end-to-end sessions with real learners.
- [ ] Improve based on observed failure cases.

## v0.2.0 — Reliable learning records
- [ ] Define progress update and migration rules.
- [ ] Add explicit evidence records for mastery decisions.
- [ ] Add spaced-repetition scheduling policy.
- [ ] Add import/export examples across agent sessions.
- [ ] Add evaluation fixtures for common teaching failures.

## v0.3.0 — Agent interoperability
- [ ] Test installation and behavior across multiple agents.
- [ ] Document capability detection for file access, browsing, and execution.
- [ ] Add optional MCP integration only where it provides clear value.
- [ ] Add compatibility test matrix.

## v0.4.0 — Subject ecosystem
- [ ] Publish subject authoring guide and review checklist.
- [ ] Add more independently reviewed subject modules.
- [ ] Add module metadata and version compatibility.
- [ ] Establish community contribution workflow.

## Later — Full learning ecosystem
- [ ] Optional web dashboard.
- [ ] Optional local-first learner data manager.
- [ ] Optional resource indexing and citation tools.
- [ ] Optional interactive lab integrations.
- [ ] Accessibility and localization improvements.

## Explicit non-goals for the first releases
- Building a custom foundation model.
- Requiring a hosted backend or account.
- Hosting video courses.
- Social feeds, leaderboards, or gamification by default.
- Claiming mastery based only on lesson completion or one quiz.
