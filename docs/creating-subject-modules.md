# Creating subject modules

Start with `subjects/_template/subject.md`.

A useful module defines:
1. Audience, prerequisites, and learning goals.
2. Observable outcomes and topic dependencies.
3. A staged sequence that moves from foundations to application.
4. Practice tasks, assessments, and common misconceptions.
5. Safety, legal, accessibility, and resource notes relevant to the subject.

Prefer small, reviewable modules over giant content dumps. A subject module should guide the tutor's teaching decisions, not attempt to contain an entire textbook.
