# Brand identity

## Positioning
**Learn Anything** is an open-source adaptive learning engine for AI agents.

Tagline: **Learn anything. Actually understand it.**

One-sentence description: Build a learning path, teach one concept at a time, test real understanding, adapt to the learner, and keep progress portable.

## Visual system
- Ink: `#101522`
- Deep blue: `#1B2440`
- Violet: `#7C5CFC`
- Teal: `#21C6B7`
- Off-white: `#F5F7FF`
- Typeface: system sans-serif / Inter where available
- Mark: open book with a connected learning path

## Voice
Clear, evidence-led, optimistic without hype. Describe current capabilities separately from future goals. Never imply the project has a hosted platform, universal rendering runtime, or validated learning outcomes until those exist.
