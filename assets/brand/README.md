# Brand identity

## Positioning
**Learn Anything** is an open-source adaptive learning engine for AI agents.

Tagline: **Learn anything. Actually understand it.**

One-sentence description: Build a learning path, teach one concept at a time, test real understanding, adapt to the learner, and keep progress portable.

## Visual system
- Ink: `#101522`
- Deep blue: `#1B2440`
- Violet: `#9B5CFF`
- Blue: `#6474FF`
- Teal: `#21D4C2`
- Off-white: `#F5F7FF`
- Typeface: system sans-serif / Inter where available
- Mark: flowing open pages with a path crossing them and a small guiding star; the path represents discovery and connected understanding.

## Voice
Clear, evidence-led, optimistic without hype. Describe current capabilities separately from future goals. Never imply the project has a hosted platform, universal rendering runtime, or validated learning outcomes until those exist.

## Assets
- `assets/learn-anything-mark.svg`: primary repository mark, designed to remain legible as an avatar and favicon.
- `assets/social-preview.svg`: 1280×640 source artwork for the GitHub social preview. GitHub repository settings may require a PNG or JPG upload; export this artwork before setting the social preview.
